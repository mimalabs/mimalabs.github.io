# MIMA LABS V30

V30 focuses on responsive shopping clarity without changing the launch content or availability model.

- Hero book area is now a manual featured-book carousel: one large cover, previous/next peeks, arrows and dots. No autoplay.
- The active hero cover keeps the holographic hover effect and uses the same Amazon availability rules as the catalog.
- Product cards have one compact metadata line instead of multiple chips.
- Small landscape uses a horizontal editorial card (cover left, copy right) so the cover stays large and text stays readable.
- Portrait shows exactly one product per horizontal swipe with a large centered cover and compact copy below.
- Very short screens remove secondary text before reducing cover size.
- Unavailable editions remain non-clickable and use a single quiet “Coming soon” state.
- Farm EN and Farm FR direct Amazon links remain unchanged.
