MIMA LABS V20 — unified responsive book gallery

This version rebuilds the Books section around one responsive visual system:
- full cover artwork is always preserved (no crop)
- covers share one optical size and baseline within each screen mode
- large / medium landscape sizes are driven by available viewport height
- portrait uses exactly one full product per horizontal viewport
- portrait Books section is constrained to the available viewport height
- the cover automatically grows into all vertical room left after title + product copy
- very short screens progressively trim explanatory copy rather than clipping the artwork
- the holographic cover hover effect from V19 is preserved
- Growing Library follows the same cover geometry as the published books

No SEO, localized cover, Amazon availability, hamburger, cookie, legal, analytics, or localization functionality was removed.
