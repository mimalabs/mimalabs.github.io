# MIMA LABS V33

V33 simplifies the home showcase again and gives the books more visual priority.

## Home
- Removed the book carousel entirely.
- Farm, Halloween and Christmas are shown together as three large static cover cards.
- Cards overlap slightly so each cover can stay large while still fitting the hero.
- Available editions remain directly clickable to Amazon.
- Unavailable editions remain muted and non-clickable with the existing small Coming Soon state.
- Holographic / premium hover treatment remains for available covers.

## Books
- Covers are larger across landscape, compact landscape and portrait.
- Full cover artwork is still always visible; nothing is cropped.
- Compact landscape hides non-essential intro text before shrinking the books.
- Short landscape hides the age line before shrinking the books further.
- Portrait keeps one product per swipe but allows the cover to use more of the available height/width.
- The information hierarchy remains minimal: cover, age, title, Amazon / Coming soon.

Everything else remains unchanged: localized covers, Amazon availability, SEO, socials, legal pages, analytics controls and GitHub Pages deployment.
