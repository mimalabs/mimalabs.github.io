# MIMA LABS V35 — centered responsive cleanup

V35 is a stability-focused cleanup of the Home and Books showcase areas.

## What changed
- One centered content axis across the website (`1480px` maximum shell).
- Hero uses a clean two-column layout in landscape with three equal book cards.
- Portrait hero uses a centered three-cover fan: all three books stay visible without a slider.
- Books use the real cover artwork as the visual card; old extra framing/badges are neutralized.
- Landscape Books = three aligned columns.
- Portrait Books = one large complete cover per swipe with only minimal dots.
- Unavailable editions remain muted, non-clickable and use one small Coming soon state.
- Compact/short viewports reduce secondary copy before shrinking primary artwork.

## Kept intact
- Farm EN and FR Amazon links.
- Halloween and Christmas collections.
- Six locales and localized covers.
- Social links, SEO, legal pages, cookie preferences and GitHub Pages setup.
