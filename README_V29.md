# MIMA LABS V29

V29 keeps the V28 launch-candidate design and makes three focused refinements:

1. **Larger hero covers in landscape** — Farm, Halloween and Christmas now scale to the actual hero artwork area instead of inheriting the earlier two-book height cap. The full cover artwork remains uncropped and the existing hover/shine interaction is unchanged.
2. **Simpler unavailable state** — unavailable Books cards use the existing muted cover treatment plus one compact localized “Coming soon” pill. The duplicated cover badge and explanatory sentence were removed.
3. **Direct Amazon listings** — Farm English now links to ASIN `B0HK7ZLTJP` on Amazon.com and Farm French to ASIN `B0HK8J88KD` on Amazon.fr. All other language/product combinations remain non-interactive until a URL is added to `content/products.ts`.

No other storefront, SEO, localization, social, legal, analytics, GitHub Pages, or responsive-section behavior was intentionally changed.
